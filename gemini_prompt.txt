━━━━━━━━━━━━━━━━━━━━━━━━━━━━
上記 10 人それぞれについて、以下の形式のJSONオブジェクトを作り、
配列にまとめてください。

条件:
- name: 表示名またはハンドル名をそのまま使用
- bio: 100〜150文字。年齢・職業は不明なら推測しない。投稿から読み取れる性格・口調・興味を自然な日本語で記述
- id: 0始まりの連番（0〜9）
- other_info.hobbies: 投稿から推測される趣味・関心事
- other_info.reaction_triggers: 反応しやすそうなトピック
- other_info.reaction_avoid: スルーしそうなトピック
- other_info.follow_policy: どんなユーザーをフォロー/アンフォローしそうか
- other_info.tone_examples: 実際の投稿から抜粋した口調・フレーズの例を3つ（改行区切り）

出力形式（JSONのみ。説明文・```不要）:
[
  {
    "name": "表示名",
    "bio": "性格・口調の説明",
    "id": 0,
    "other_info": {
      "handle": "@handle",
      "followers": 数値,
      "hobbies": "趣味・関心",
      "reaction_triggers": "反応しやすいトピック",
      "reaction_avoid": "スルーするトピック",
      "follow_policy": "フォロー/アンフォローの基準",
      "tone_examples": "・フレーズ1\n・フレーズ2\n・フレーズ3"
    }
  },
  ...
]
